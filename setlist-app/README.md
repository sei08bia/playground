# セトリノート

ライブのセットリストと、曲ごとの感想・MCの内容をメモできる静的Webアプリです。サーバーもログインも不要で、スマホのブラウザで `index.html` を開けばすぐ使えます。

- 記録はその端末のブラウザ（localStorage）に保存されます。一覧画面の「バックアップ」からファイルに書き出し・読み込みができます。
- ライブ情報でアーティスト名を入れると、写真つきの候補から本人を選べます（写真は Deezer の公開API）。
- 曲は「曲を選ぶ」でジャケット一覧（アルバム/シングル）から作品を開いて収録曲をタップするか、曲名を打って出る候補から追加できます（Apple Music の公開検索API。端末に7日間キャッシュ）。一覧にない曲は手入力でOK。
- 「プレイリストを取り込む」から、Apple Music などのプレイリストの曲名リストを貼り付けて、曲ごとに感想を書けるノートを作れます（Mac のミュージックAppからのコピーや「曲名 - アーティスト」形式に対応）。
- 「Spotifyのプレイリストから選ぶ」で Spotify にサインインし、自分のプレイリストを選んで取り込めます（PKCE方式でサーバー不要。app.js の SPOTIFY_CLIENT_ID に Spotify 開発者ダッシュボードの Client ID を設定）。
- シェアは4通り: Xにポスト / 画像を作って保存・共有 / 閲覧用リンク（データをURLに埋め込むのでサーバー不要）/ テキストをコピー。感想・MCメモを含めるかは選べます。

ローカルで試す場合:

```sh
cd setlist-app && python3 -m http.server 8000
```
