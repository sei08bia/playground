# セトリノート

ライブのセットリストと、曲ごとの感想・MCの内容をメモできる静的Webアプリです。サーバーもログインも不要で、スマホのブラウザで `index.html` を開けばすぐ使えます。

- 記録はその端末のブラウザ（localStorage）に保存されます。一覧画面の「バックアップ」からファイルに書き出し・読み込みができます。
- 曲は、アーティストの曲一覧（Apple Music の公開検索APIから取得し、端末に7日間キャッシュ）から選ぶか、曲名を打って出る候補から追加できます。一覧にない曲は手入力でOK。
- シェアは4通り: Xにポスト / 画像を作って保存・共有 / 閲覧用リンク（データをURLに埋め込むのでサーバー不要）/ テキストをコピー。感想・MCメモを含めるかは選べます。

ローカルで試す場合:

```sh
cd setlist-app && python3 -m http.server 8000
```
